# СпортПульс

Основа сайта для новостного спортивного паблика. Чистые HTML/CSS/JS, без сборки и зависимостей.

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Структура

```
index.html      — главная: главная новость, лента, фильтр по видам спорта (?cat=football)
article.html    — страница новости (?id=1)
css/style.css   — стили (адаптив, тёмная тема по системной настройке)
js/data.js      — данные: категории, новости, результаты матчей
js/main.js      — рендеринг страниц
```

## Как добавить новость

Добавьте объект в массив `NEWS` в `js/data.js`:

```js
{ id: 8, category: "football", title: "...", excerpt: "...", body: ["абзац 1", "абзац 2"],
  author: "Редакция", date: "2026-11-10T12:00:00", views: 0 }
```

`featured: true` — новость попадёт в главный блок на главной.
