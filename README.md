# FC Durum

Официальный сайт любительской футбольной команды **FC Durum**: новости, состав, матчи.
Статический сайт (HTML/CSS/JS), без сборки — работает на GitHub Pages.

## Разделы (ссылки)

- `#news` — новости (главная), `#news-1` — отдельная новость
- `#team` — состав, `#player-3` — страница игрока
- `#table` — турнирная таблица АПЛ (данные в `LEAGUE` в `js/data.js`, очки и места считаются сами)
- `#ucl` — Лига чемпионов: история (`UCL.history`) и ближайший этап (`UCL.next`) в `js/data.js`
- `#matches` — расписание и результаты
- `#club` — о клубе

## Где что лежит

```
index.html          — страница сайта
css/style.css       — стили (красно-чёрная айдентика, светлая и тёмная тема)
js/data.js          — ВСЕ ДАННЫЕ: клуб, игроки, новости, матчи
js/main.js          — отрисовка страниц
images/emblem.svg   — эмблема клуба
images/players/     — фото игроков
images/news/        — картинки к новостям
```

## Как обновлять

Всё содержимое — в `js/data.js`:

- **Новость** — объект в `NEWS` (`image: "images/news/2.jpg"`, `players: [1, 5]` — отметить игроков).
- **Игрок** — объект в `PLAYERS` (`photo: "images/players/1.jpg"`).
- **Результат матча АПЛ** — строка в `LEAGUE.results`: `{ round: 4, home: "FC Durum", away: "FC Shegly", score: "3:1" }`.
  Таблица, форма команд и раздел «Матчи» пересчитываются сами.
- **Ближайший матч** — объект в `MATCHES`: `{ date: "2026-11-20T18:00:00", opponent: "FC Shegly", home: true }`

## Обновление кэша

После каждого изменения поднимайте номер `?v=...` у `css/style.css`, `js/data.js`, `js/main.js` в `index.html`,
иначе браузеры посетителей до 10 минут могут показывать старую версию.
